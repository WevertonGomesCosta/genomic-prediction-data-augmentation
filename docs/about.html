Projeto

Tutorial em workflowr para estudar predição genômica com GBLUP, tamanho de amostra real e aumento de dados (Data Augmentation) via Mixup.

O repositório foi organizado para priorizar uma leitura didática e sequencial. O código metodologicamente relevante aparece diretamente nos módulos analíticos, acompanhado da explicação do objetivo e da interpretação dos resultados de cada etapa.

A fonte original e o procedimento de preparação do conjunto analítico serão documentados separadamente após a conclusão da auditoria de proveniência dos dados.
