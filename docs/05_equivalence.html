5. Equivalência com T100

Weverton Gomes da Costa

2026-08-17

1. Objetivo

A curva de aprendizado mostrou que T75 apresenta desempenho próximo de T100. Agora precisamos responder uma pergunta mais específica:

A diferença é pequena o suficiente para considerar uma amostra reduzida praticamente equivalente a T100?

Não procuramos provar que as correlações são exatamente iguais. Definimos uma margem de diferença considerada pequena para este estudo:

\[ \delta = 0.05. \]

Neste tutorial, delta = 0.05 representa a menor diferença de interesse científico, conhecida pela sigla SESOI (Smallest Effect Size of Interest). Essa margem foi definida especificamente para este estudo e não deve ser interpretada como um limiar universal para estudos de predição genômica.

Uma estratégia será considerada equivalente quando o intervalo de confiança do efeito estiver totalmente dentro de:

\[ [-0.05,\,+0.05]. \]

2. Resultados de referência com dados reais

Esta etapa utiliza apenas os 120 resultados com indivíduos reais já produzidos na Etapa 4. Nenhum GBLUP é reajustado.

3. Diferenças pareadas contra T100

Cada cenário reduzido é comparado com T100 na mesma repetição. Isso é possível porque ambos foram avaliados exatamente nos mesmos 276 indivíduos de validação.

t100 <- baseline[
  baseline$proporcao_pool == PROP_T100,
  c("repeticao", "correlacao")
]

names(t100)[2] <- "correlacao_T100"

reduzidos <- baseline[
  baseline$proporcao_pool < PROP_T100,
  c(
    "repeticao",
    "proporcao_pool",
    "n_treino",
    "correlacao"
  )
]

diferencas <- merge(
  reduzidos,
  t100,
  by = "repeticao"
)

diferencas$delta_cor <-
  diferencas$correlacao -
  diferencas$correlacao_T100

resumo_diferencas <- aggregate(
  delta_cor ~ proporcao_pool,
  data = diferencas,
  FUN = mean
)

names(resumo_diferencas) <- c(
  "Proporção do pool",
  "Diferença média de correlação"

4. Por que corrigir o erro-padrão?

As 30 repetições não são 30 experimentos completamente independentes. Os conjuntos de validação são sorteados da mesma população e um mesmo indivíduo pode aparecer em várias repetições.

Por isso usamos a aproximação de Nadeau-Bengio para aumentar o erro-padrão em relação ao teste pareado ingênuo. O procedimento original foi proposto para comparações sob reamostragem repetida; aqui utilizamos esse erro-padrão corrigido dentro do TOST como uma adaptação para a análise de equivalência:

\[ SE_{NB}= \sqrt{ \left( \frac{1}{R}+ \frac{n_{test}}{n_{train}} \right)s_d^2 }. \]

Aqui:

  • R = 30 repetições;
  • n_test = 276 indivíduos de validação;
  • n_train = 1103 para a análise primária;
  • s_d é o desvio-padrão das diferenças pareadas.

5. TOST com correção de Nadeau-Bengio

O TOST (Two One-Sided Tests) é um procedimento de equivalência baseado em dois testes unilaterais. Para declarar equivalência, precisamos rejeitar simultaneamente que a diferença seja menor ou igual a -0.05 e que seja maior ou igual a +0.05.

O código abaixo apresenta diretamente o cálculo utilizado.

DELTA <- 0.05
ALPHA <- 0.05

resultado_equivalencia <- data.frame()

for (proporcao in PROPORCOES_REDUZIDAS) {
  d <- diferencas$delta_cor[
    diferencas$proporcao_pool == proporcao
  ]

  media_d <- mean(d)
  sd_d <- sd(d)

  fator_NB <-
    1 / N_REP +
    N_TEST / N_TRAIN_POOL

  se_NB <- sqrt(
    fator_NB * sd_d^2
  )

  gl <- length(d) - 1

  p_inferior <- 1 - pt(
    (media_d + DELTA) / se_NB,
    df = gl
  )

  p_superior <- pt(
    (media_d - DELTA) / se_NB,
    df = gl
  )

  t_critico <- qt(
    1 - ALPHA,
    df = gl
  )

  ic90_inf <- media_d - t_critico * se_NB
  ic90_sup <- media_d + t_critico * se_NB

  p_TOST <- max(
    p_inferior,
    p_superior
  )

  equivalente <-
    p_inferior < ALPHA &&
    p_superior < ALPHA &&
    ic90_inf > -DELTA &&
    ic90_sup < DELTA

  resultado_equivalencia <- rbind(
    resultado_equivalencia,
    data.frame(
      Proporcao = proporcao,
      N_real = unique(
        diferencas$n_treino[
          diferencas$proporcao_pool == proporcao
        ]
      ),
      Delta_cor_media = media_d,
      SE_NB = se_NB,
      IC90_inf = ic90_inf,
      IC90_sup = ic90_sup,
      p_TOST = p_TOST,
      Equivalente = equivalente
    )
  )
}

7. Análise de sensibilidade usando o tamanho real de treinamento

Na análise principal usamos n_train = 1103, correspondente ao pool de treinamento. Como verificação de sensibilidade, repetimos a correção usando o tamanho efetivo de cada estratégia: 275, 551 ou 827.

sensibilidade <- data.frame()

for (proporcao in PROPORCOES_REDUZIDAS) {
  d <- diferencas$delta_cor[
    diferencas$proporcao_pool == proporcao
  ]

  n_train_efetivo <- unique(
    diferencas$n_treino[
      diferencas$proporcao_pool == proporcao
    ]
  )

  stopifnot(length(n_train_efetivo) == 1L)

  media_d <- mean(d)
  sd_d <- sd(d)

  fator_NB <-
    1 / N_REP +
    N_TEST / n_train_efetivo

  se_NB <- sqrt(
    fator_NB * sd_d^2
  )

  gl <- length(d) - 1

  p_inferior <- 1 - pt(
    (media_d + DELTA) / se_NB,
    df = gl
  )

  p_superior <- pt(
    (media_d - DELTA) / se_NB,
    df = gl
  )

  t_critico <- qt(
    1 - ALPHA,
    df = gl
  )

  ic90_inf <- media_d - t_critico * se_NB
  ic90_sup <- media_d + t_critico * se_NB

  equivalente <-
    p_inferior < ALPHA &&
    p_superior < ALPHA &&
    ic90_inf > -DELTA &&
    ic90_sup < DELTA

  sensibilidade <- rbind(
    sensibilidade,
    data.frame(
      Proporcao = proporcao,
      N_train_correcao = n_train_efetivo,
      Delta_cor_media = media_d,
      IC90_inf = ic90_inf,
      IC90_sup = ic90_sup,
      p_TOST = max(p_inferior, p_superior),
      Equivalente = equivalente
    )
  )
}

8. Conclusão desta etapa

Sem aumento de dados, o menor conjunto real equivalente a T100 é:

\[ \boxed{T75 = 827\text{ indivíduos reais}}. \]

Esse valor será a referência da próxima etapa. O aumento de dados só terá benefício prático se permitir que T50 ou T25 também se tornem equivalentes a T100.
