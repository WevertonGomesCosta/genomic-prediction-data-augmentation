7. Mixup informado pela população

Weverton Gomes da Costa

2026-08-18

1. Objetivo

A Etapa 6 avaliou quatro parametrizações usuais de Mixup: lambda = 0.5 e distribuições simétricas Beta(alpha, alpha) com alpha = 0.1, 0.2 e 0.4. Nenhuma delas tornou T25 ou T50 equivalente a T100.

Nesta etapa mantemos o Mixup padrão e modificamos somente a forma de definir alpha. Em vez de escolher uma pequena grade de valores, estimamos um único parâmetro a partir da relação entre a variabilidade genômica e a variabilidade residual da população analítica.

O objetivo principal continua sendo verificar se o aumento de dados permite que

\[ T_{25}+DA \]

ou

\[ T_{50}+DA \]

atinja desempenho praticamente equivalente ao T100 formado por 1.103 indivíduos reais. T75 + DA é mantido como diagnóstico, porque a Etapa 5 já mostrou que T75 sem aumento de dados é equivalente a T100.

A calibração do parâmetro utiliza os fenótipos dos 1.379 indivíduos e, por isso, é tratada explicitamente como uma análise population-informed/oracle. Essa calibração não representa validação preditiva cega. Depois que o parâmetro é estimado, os pseudoindivíduos de cada cenário são construídos exclusivamente a partir dos indivíduos reais daquele conjunto de treinamento, e os fenótipos dos indivíduos de validação permanecem mascarados no ajuste preditivo.

2. Parâmetro populacional da mistura

O componente genômico usado nas etapas anteriores é ajustado no BGLR como

\[ g \sim N(0,G\sigma_u^2), \]

em que G é a matriz de relacionamento genômico construída na Etapa 3 e \(\sigma_u^2\) é o parâmetro de variância associado ao kernel.

Como a escala numérica de G influencia a interpretação direta de \(\sigma_u^2\), usamos a variabilidade média induzida por G na população analítica. Definimos

\[ P=I-\frac{\mathbf{1}\mathbf{1}^{\mathsf T}}{n} \]

e

\[ c_G= \frac{\operatorname{tr}(PG)}{n-1}. \]

A variabilidade genômica populacional correspondente é

\[ V_{G,pop}=c_G\sigma_u^2. \]

A razão entre o desvio-padrão genômico populacional e o desvio-padrão residual é

\[ R_{Ge,pop} = \sqrt{ \frac{V_{G,pop}}{\sigma_e^2} } = \sqrt{ \frac{c_G\sigma_u^2}{\sigma_e^2} }. \]

Esse parâmetro é adimensional. Não o denominamos CV_A/CV_e, porque o coeficiente de variação residual não possui interpretação convencional quando o efeito residual tem média zero.

A relação correspondente com a proporção de variância genômica é

\[ h_G^2= \frac{V_{G,pop}} {V_{G,pop}+\sigma_e^2}, \]

de forma que

\[ R_{Ge,pop} = \sqrt{ \frac{h_G^2}{1-h_G^2} }. \]

A regra proposta para o Mixup é então

\[ \lambda \sim Beta(\alpha_{pop},\alpha_{pop}), \]

com

\[ \boxed{ \alpha_{pop} = E(R_{Ge,pop}\mid y) }. \]

Portanto, alpha_pop é a média posterior da própria razão de desvios-padrão, calculada a partir das amostras MCMC. Não há tuning, busca em grade ou seleção do valor de alpha com base no desempenho da validação.

5. Distribuição de lambda determinada pela população

Como a distribuição é simétrica,

\[ E(\lambda)=0.5. \]

Para Beta(alpha_pop, alpha_pop), o desvio-padrão teórico é

\[ SD(\lambda) = \frac{1} {2\sqrt{2\alpha_{pop}+1}}. \]

7. Ajuste dos 90 cenários

A geração dos pseudoindivíduos segue exatamente as equações da Etapa 6:

\[ \widetilde M = \lambda M_i+(1-\lambda)M_j \]

e

\[ \widetilde y = \lambda y_i+(1-\lambda)y_j. \]

Os dois doadores de uma mesma mistura são sempre indivíduos reais distintos do conjunto de treinamento. Há reposição entre pseudoindivíduos, mas nenhum indivíduo de validação pode atuar como doador.

A matriz expandida usa as mesmas frequências alélicas e o mesmo denominador de VanRaden empregados na Etapa 3. O bloco real-real de G é preservado integralmente.

resultados_da_calculados <- data.frame()

for (s in seq_len(nrow(cenarios_da))) {

  cenario <- cenarios_da[s, ]
  proporcao_chave <- as.character(
    cenario$proporcao_pool
  )

  split <- splits_mestre[[proporcao_chave]][[cenario$repeticao]]

  treino <- split$treino
  validacao <- split$valid

  stopifnot(
    length(
      intersect(
        treino,
        validacao
      )
    ) == 0
  )

  M_train <- M[
    treino,
    ,
    drop = FALSE
  ]

  y_train <- y[
    treino
  ]

  n_real <- length(
    treino
  )

  n_syn <- cenario$n_syn

  # Semente da geração dos pseudoindivíduos.
  seed_da <-
    SEED_DA_BASE +
    as.integer(
      cenario$proporcao_pool * 100
    ) * 100 +
    cenario$repeticao

  set.seed(
    seed_da
  )

  idx1 <- sample(
    seq_len(n_real),
    n_syn,
    replace = TRUE
  )

  idx2_base <- sample(
    seq_len(n_real - 1),
    n_syn,
    replace = TRUE
  )

  idx2 <- ifelse(
    idx2_base >= idx1,
    idx2_base + 1L,
    idx2_base
  )

  stopifnot(
    all(idx1 != idx2)
  )

  lambda <- rbeta(
    n_syn,
    shape1 = alpha_pop,
    shape2 = alpha_pop
  )

  M_syn <-
    lambda * M_train[
      idx1,
      ,
      drop = FALSE
    ] +
    (1 - lambda) * M_train[
      idx2,
      ,
      drop = FALSE
    ]

  y_syn <-
    lambda * y_train[idx1] +
    (1 - lambda) * y_train[idx2]

  stopifnot(
    nrow(M_syn) == n_syn,
    length(y_syn) == n_syn
  )

  # Expansão da matriz de relacionamento.
  Z_syn <- sweep(
    M_syn,
    2,
    2 * p,
    FUN = "-"
  )

  G_syn_real <- tcrossprod(
    Z_syn,
    Z
  ) / denominador

  G_syn_syn <- tcrossprod(
    Z_syn
  ) / denominador

  G_expanded <- rbind(
    cbind(
      G,
      t(G_syn_real)
    ),
    cbind(
      G_syn_real,
      G_syn_syn
    )
  )

  idx_syn <- (n + 1):(
    n + n_syn
  )

  G_expanded[
    cbind(
      idx_syn,
      idx_syn
    )
  ] <-
    G_expanded[
      cbind(
        idx_syn,
        idx_syn
      )
    ] +
    EPS_DIAGONAL

  stopifnot(
    max(
      abs(
        G_expanded -
          t(G_expanded)
      )
    ) < TOL_SIMETRIA
  )

  stopifnot(
    max(
      abs(
        G_expanded[
          seq_len(n),
          seq_len(n)
        ] -
          G
      )
    ) < TOL_BLOCO_REAL
  )

  # Fenótipos observados apenas para treinamento real e sintéticos.
  y_modelo <- c(
    rep(
      NA_real_,
      n
    ),
    y_syn
  )

  y_modelo[
    treino
  ] <- y_train

  reais_fora_treino <- setdiff(
    seq_len(n),
    treino
  )

  stopifnot(
    all(
      is.na(
        y_modelo[
          validacao
        ]
      )
    ),
    all(
      is.na(
        y_modelo[
          reais_fora_treino
        ]
      )
    ),
    sum(
      !is.na(
        y_modelo
      )
    ) == N_T100
  )

  # Mesmo modelo preditivo das etapas anteriores.
  ETA <- list(
    list(
      K = G_expanded,
      model = "RKHS"
    )
  )

  seed_bglr <-
    SEED_BGLR_BASE +
    as.integer(
      cenario$proporcao_pool * 100
    ) * 100 +
    cenario$repeticao

  set.seed(
    seed_bglr
  )

  saveAt_fit <- file.path(
    tempdir(),
    paste0(
      "07_fit_",
      s,
      "_"
    )
  )

  ajuste <- BGLR::BGLR(
    y = y_modelo,
    ETA = ETA,
    nIter = N_ITER,
    burnIn = BURN_IN,
    saveAt = saveAt_fit,
    verbose = FALSE
  )

  predicao <- ajuste$yHat[
    validacao
  ]

  observado <- y[
    validacao
  ]

  correlacao <- cor(
    observado,
    predicao
  )

  RMSE <- sqrt(
    mean(
      (
        observado -
          predicao
      )^2
    )
  )

  MAE <- mean(
    abs(
      observado -
        predicao
    )
  )

  calibracao <- lm(
    observado ~ predicao
  )

  slope_calibracao <- unname(
    coef(
      calibracao
    )[2]
  )

  resultados_da_calculados <- rbind(
    resultados_da_calculados,
    data.frame(
      config_mistura = CONFIG_MISTURA,
      alpha = alpha_pop,
      repeticao = cenario$repeticao,
      proporcao_pool = cenario$proporcao_pool,
      n_real = n_real,
      n_syn = n_syn,
      n_total_treino = n_real + n_syn,
      correlacao = correlacao,
      RMSE = RMSE,
      MAE = MAE,
      slope_calibracao = slope_calibracao,
      media_lambda = mean(lambda),
