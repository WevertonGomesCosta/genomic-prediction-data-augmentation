1. Objetivo

Um modelo de predição precisa ser avaliado em indivíduos que não forneceram fenótipos durante o treinamento. Caso contrário, mediríamos principalmente a capacidade de reproduzir dados já observados, e não a capacidade de predizer indivíduos ainda não fenotipados.

Por isso, cada repetição é dividida em duas partes independentes quanto ao uso do fenótipo:

  • aproximadamente 20% dos 1.379 indivíduos são separados para validação;
  • os 80% restantes formam o conjunto completo de treinamento, chamado T100;
  • dentro de T100 são criadas amostras menores de 25%, 50% e 75%.

Os conjuntos menores são aninhados:

\[ T_{25}\subset T_{50}\subset T_{75}\subset T_{100}. \]

Isso significa que os indivíduos usados em T25 também estão em T50, os de T50 estão em T75 e assim por diante. Dessa forma, a comparação entre tamanhos de amostra representa a adição progressiva de indivíduos ao mesmo conjunto de referência, em vez da comparação entre amostras independentes.

3. Parâmetros do desenho amostral

Utilizamos 30 repetições independentes do sorteio de validação. Em cada uma delas, 20% dos indivíduos são reservados para validação externa. As sementes são definidas previamente para que o mesmo desenho amostral seja utilizado em todas as etapas seguintes.

PROP_VALIDACAO <- 0.20
PROPORCOES_TREINO <- c(0.25, 0.50, 0.75, 1.00)
N_REP <- 30
SEEDS_REP <- 101 * seq_len(N_REP)

N_VALIDACAO <- round(n * PROP_VALIDACAO)
N_POOL <- n - N_VALIDACAO

c(
  validacao = N_VALIDACAO,
  T100 = N_POOL
)
validacao      T100 
      276      1103

Com 1.379 indivíduos, cada repetição contém:

\[ 1379 = 1103_{\text{treinamento}} + 276_{\text{validação}}. \]

O termo T100 refere-se, portanto, a 100% do pool disponível para Treinamento naquela repetição, e não a 100% dos 1.379 indivíduos da população analítica.

4. Sorteio da validação e formação dos conjuntos aninhados

Para cada repetição, primeiro sorteamos os 276 indivíduos de validação. Os 1.103 indivíduos restantes formam T100.

Em seguida, uma única permutação aleatória de T100 é criada. T25, T50 e T75 são obtidos usando partes progressivamente maiores dessa mesma ordem aleatória. É essa construção que garante o aninhamento entre os quatro tamanhos de Treinamento.

# Estrutura que armazenará os 30 splits de cada tamanho de treinamento.
splits_mestre <- setNames(
  lapply(
    PROPORCOES_TREINO,
    function(x) vector("list", N_REP)
  ),
  as.character(PROPORCOES_TREINO)
)

for (rep in seq_len(N_REP)) {
  set.seed(SEEDS_REP[rep])

  # 1. Sorteia a validação externa da repetição atual.
  validacao <- sort(
    sample(
      seq_len(n),
      N_VALIDACAO,
      replace = FALSE
    )
  )

  # 2. Os indivíduos restantes formam o pool completo T100.
  pool <- setdiff(
    seq_len(n),
    validacao
  )

  # 3. Uma única ordem aleatória será compartilhada por T25, T50, T75 e T100.
  ordem_pool <- sample(
    pool,
    length(pool),
    replace = FALSE
  )

  tamanhos <- c(
    floor(0.25 * length(pool)),
    floor(0.50 * length(pool)),
    floor(0.75 * length(pool)),
    length(pool)
  )

  # 4. Cada conjunto maior contém integralmente o conjunto anterior.
  for (i in seq_along(PROPORCOES_TREINO)) {
    proporcao <- PROPORCOES_TREINO[i]

    treino <- sort(
      ordem_pool[seq_len(tamanhos[i])]
    )

    splits_mestre[[as.character(proporcao)]][[rep]] <- list(
      treino = treino,
      valid = validacao,
      pool = sort(pool),
      seed = SEEDS_REP[rep]
    )
  }
}

5. Verificação do desenho amostral

As verificações abaixo confirmam duas propriedades essenciais do desenho:

  1. T25, T50, T75 e T100 permanecem aninhados em todas as repetições;
  2. nenhum indivíduo da validação pertence ao conjunto de treinamento da mesma repetição.
for (rep in seq_len(N_REP)) {
  # Recupera os quatro conjuntos de treinamento e a validação da repetição.
  t25 <- splits_mestre[["0.25"]][[rep]]$treino
  t50 <- splits_mestre[["0.5"]][[rep]]$treino
  t75 <- splits_mestre[["0.75"]][[rep]]$treino
  t100 <- splits_mestre[["1"]][[rep]]$treino
  validacao <- splits_mestre[["1"]][[rep]]$valid

  # Confirma o aninhamento e a independência entre treinamento e validação.
  stopifnot(all(t25 %in% t50))
  stopifnot(all(t50 %in% t75))
  stopifnot(all(t75 %in% t100))
  stopifnot(length(intersect(t100, validacao)) == 0)

  # Confirma os tamanhos definidos pelo desenho amostral.
  stopifnot(length(t25) == 275)
  stopifnot(length(t50) == 551)
  stopifnot(length(t75) == 827)
  stopifnot(length(t100) == 1103)
  stopifnot(length(validacao) == 276)
}
