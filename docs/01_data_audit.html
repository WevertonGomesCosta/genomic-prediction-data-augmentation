1. Objetivo

Antes de ajustar qualquer modelo de predição genômica, precisamos conhecer o arquivo analítico e verificar se sua estrutura corresponde ao que será usado no restante do tutorial.

Neste conjunto de dados:

  • cada linha representa um indivíduo;
  • a coluna yield contém o fenótipo de produtividade;
  • as demais colunas representam SNPs;
  • cada SNP é codificado como 0, 1 ou 2, correspondendo ao número de cópias do alelo contado naquele marcador.

A auditoria não modifica os dados. Ela apenas verifica a estrutura do arquivo e salva os objetos que serão usados na próxima etapa.

2. Leitura do arquivo

O arquivo analítico deve estar em data/dados_gblup.csv.

DATA_FILE <- "data/dados_gblup.csv"

if (!file.exists(DATA_FILE)) {
  stop(
    "Arquivo não encontrado: ", DATA_FILE,
    ". Coloque dados_gblup.csv dentro da pasta data/."
  )
}

dados <- read.csv(
  DATA_FILE,
  check.names = FALSE
)

dim(dados)
[1] 1379 4326

O projeto validado possui 1.379 indivíduos e 4.326 colunas: uma coluna fenotípica e 4.325 SNPs.

3. Identificação do fenótipo e dos SNPs

Primeiro separamos o nome da característica fenotípica dos nomes dos marcadores.

if (sum(names(dados) == "yield") != 1) {
  stop("O arquivo deve possuir exatamente uma coluna chamada yield.")
}

if (anyDuplicated(names(dados)) > 0) {
  stop("Existem nomes de colunas duplicados.")
}

marker_names <- setdiff(
  names(dados),
  "yield"
)

length(marker_names)
[1] 4325

Os nomes dos SNPs seguem o padrão adotado no arquivo analítico, por exemplo Gm01_..._A_G.

pattern_snp <- "^Gm[0-9]{2}_[0-9]+_[ACGT]_[ACGT]$"

if (!all(grepl(pattern_snp, marker_names))) {
  stop("Há marcadores com nomes fora do padrão esperado.")
}

4. Construção da matriz de marcadores e do vetor fenotípico

A matriz M contém apenas os SNPs. O vetor y contém a produtividade.

M <- as.matrix(
  dados[, marker_names, drop = FALSE]
)

storage.mode(M) <- "numeric"

y <- as.numeric(
  dados$yield
)

5. Valores ausentes e codificação dos SNPs

Os modelos deste tutorial utilizam o arquivo analítico já filtrado. Por isso, não esperamos valores ausentes nos SNPs nem no fenótipo.

Também verificamos se todos os genótipos estão codificados como 0, 1 ou 2.

auditoria_valores <- data.frame(
  Verificacao = c(
    "Fenótipos ausentes",

6. Marcadores sem variação e registros duplicados

Um marcador monomórfico apresenta o mesmo valor para todos os indivíduos e não contribui para diferenciar geneticamente a população. Também verificamos se há linhas ou perfis genômicos exatamente duplicados.

n_classes <- integer(ncol(M))

for (j in seq_len(ncol(M))) {
  n_classes[j] <- length(
    unique(M[, j])
  )
}

n_monomorficos <- sum(n_classes <= 1)
n_linhas_duplicadas <- sum(duplicated(dados))
n_perfis_duplicados <- sum(
  duplicated(
    as.data.frame(M)
  )
)

auditoria_estrutura <- data.frame(
  Verificacao = c(
    "Indivíduos",
    "SNPs",
    "Marcadores monomórficos",
    "Linhas duplicadas",

  Valor = c(
