Sobre este tutorial

Este projeto mostra, passo a passo, como avaliar o efeito do tamanho da amostra real em predição genômica com GBLUP e como testar se o aumento de dados (Data Augmentation) via Mixup consegue substituir parte dos indivíduos reais de treinamento.

O objetivo é que cada página possa ser lida como uma aula prática: primeiro o conceito é apresentado, depois o código que realiza a operação é mostrado e, por fim, o resultado é interpretado.

Perguntas do projeto

  1. Qual é o menor número de indivíduos reais necessário para obter desempenho praticamente equivalente ao conjunto completo de treinamento?
  2. Podemos reduzir ainda mais esse número usando pseudoindivíduos criados por Mixup?

População e desenho

  • 1.379 indivíduos genotipados;
  • 4.325 SNPs;
  • 276 indivíduos de validação por repetição;
  • T100 = 1.103 indivíduos reais de treinamento;
  • 30 repetições de validação externa aleatória;
  • T25, T50, T75 e T100 aninhados;
  • uma matriz genômica global G;
  • GBLUP via BGLR/RKHS;
  • 10.000 iterações e período de burn-in de 5.000;
  • equivalência avaliada com margem delta = 0.05, definida como uma margem prática específica deste estudo, e correção de Nadeau-Bengio.

Caminho recomendado

1. Conhecer e auditar os dados
          ↓
2. Separar treinamento e validação
          ↓
3. Construir a matriz genômica G
          ↓
4. Ajustar o GBLUP com dados reais
          ↓
5. Testar equivalência com T100
          ↓
6. Criar pseudoindivíduos e avaliar o aumento de dados

Módulos

  1. Auditoria dos dados — o que existe no arquivo e como validamos sua estrutura.
  2. Amostragem e conjuntos aninhados — como separar treinamento e validação sem confundir os cenários.
  3. Matriz de relacionamento genômico — como os SNPs são transformados na matriz G.
  4. GBLUP com dados reais — como o modelo é ajustado e como a curva de aprendizado é obtida.
  5. Equivalência com T100 — como decidir se uma amostra menor já é suficiente.
  6. Aumento de dados — como o Mixup cria pseudoindivíduos e se isso reduz a necessidade de dados reais.

Resultado principal

Sem aumento de dados, T75 foi a menor amostra equivalente a T100:

\[ 827\text{ indivíduos reais} \approx 1103\text{ indivíduos reais}. \]

Nenhuma estratégia de Mixup tornou T25 ou T50 equivalente a T100. Portanto, nas configurações avaliadas, o aumento de dados não reduziu o número mínimo de indivíduos reais necessário.
